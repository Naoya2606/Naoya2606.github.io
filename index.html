gmail-classifier プライバシーポリシー

gmail-classifier（以下「本アプリ」）は、開発者本人の Gmail アカウントに届くメールを 自動で分類するための個人用ツールです。開発者本人以外の利用は想定していません。

1. 取得する情報

本アプリは、Gmail API を通じて次の情報を取得します。

  • メールの差出人
  • メールの件名
  • メール本文の一部

2. 利用目的

  • メールの分類と、Gmail 上でのラベル付け
  • 開発者本人が管理するツール（Notion、Google カレンダー、Discord）への記録と通知

3. 保存場所

取得した情報は、開発者本人が管理するサーバー内にのみ保存します。 メール本文はログに保存しません。

4. 第三者への提供

メールの分類のため、差出人・件名・本文の一部を Google の Gemini API に送信します。 それ以外の第三者には提供しません。

5. Google ユーザーデータの取り扱い

本アプリによる Google API から取得した情報の使用は、 Google API サービスのユーザーデータに関するポリシー （Limited Use の要件を含む）に従います。
